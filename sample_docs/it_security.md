# IT Security Handbook

Passwords must be at least 14 characters long and are rotated every 180 days. Reusing any of the
last 10 passwords is not allowed. Multi-factor authentication is mandatory for email, VPN and the
code repository.

Company laptops use full-disk encryption. Lost or stolen devices must be reported to the security
desk within 2 hours so the device can be remotely wiped.

Suspicious emails should be forwarded to phishing@company.example and never opened or answered.
Software installation requires approval from the IT service desk.
